# Technical Writing (TW) Class Documentation

Welcome to my Technical Writing repository! This project contains simple notes and documentation summarizing the tools covered in our TW class[cite: 2].

## Topics Covered
1. **LaTeX** (`latex.md`) – Professional typesetting for technical reports[cite: 2, 10].
2. **Beamer** (`beamer.md`) – Clean academic presentations using LaTeX.
3. **Doxygen** (`doxygen.md`) – Automated documentation generation from source code comments[cite: 5].
4. **Google Docs** (`googledocs.md`) – Cloud-based collaborative document editing[cite: 17].
5. **Git** (`git.md`) – Local version control tracking[cite: 41].
6. **GitHub** (`github.md`) – Remote repository hosting and pull request reviews[cite: 74, 94].
