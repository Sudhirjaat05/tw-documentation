# Beamer – Presentations in LaTeX

## What is Beamer?
Beamer is a LaTeX document class specifically designed to create clean, professional presentation slides from plain-text source files.

## Key Concepts Learned in Class
- **Document Class:** Uses `\documentclass{beamer}` instead of `article`.
- **Frames:** Every individual slide is structured inside a `\begin{frame}{Slide Title}` environment.
- **Themes & Customization:** Quickly alter visual presentation layouts using commands like `\usetheme{Madrid}`.
- **Incremental Reveals:** Using `\pause` to reveal bullet points step by step during delivery.
