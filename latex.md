# LaTeX – Document Preparation System

## What is LaTeX?
LaTeX is a professional document preparation system widely used in research and academia to create beautifully formatted reports and papers[cite: 2, 10]. Instead of manually tweaking fonts, LaTeX handles layout automatically based on plain-text formatting tags.

## Key Concepts Learned in Class
- **Document Structure:** Starts with `\documentclass{article}` and wraps content inside `\begin{document}` and `\end{document}`.
- **Formatting & Sections:** Managed easily with commands like `\section{}`, `\textbf{}`, and `\textit{}`.
- **Mathematical Equations:** Seamless rendering of math using inline `$...$` or display blocks `$$...$$`.
- **Tables & Figures:** Structuring clean data tables and importing figures.
