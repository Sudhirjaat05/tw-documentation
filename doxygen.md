# Doxygen – Automated Source Code Documentation

## What is Doxygen?
Doxygen is an open-source tool that extracts reference manuals and API documentation directly from annotated source code comments (supporting C, C++, Java, and Python)[cite: 5].

## Key Concepts Learned in Class
- **Special Comment Blocks:** Using formats like `/** ... */` or Python docstrings (`""" ... """`)[cite: 9, 10].
- **Common Tags:** 
  - `\brief` or `:param:` to describe functions and parameters[cite: 9, 10, 11].
  - `\return` or `:return:` to specify return values[cite: 9, 10, 11].
- **Configuration & Execution:** Generated via `doxygen -g Doxyfile` and compiled using `doxygen Doxyfile` to output HTML or LaTeX manuals[cite: 8, 14].
