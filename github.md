# GitHub – Remote Repository Hosting & Collaboration

## What is GitHub?
GitHub is an online hosting platform that provides remote repository storage and code review tools built around Git[cite: 74].

## Key Operations Learned in Class
- **Connecting Remotes:** `git remote add origin <URL>`[cite: 80]
- **Pushing & Pulling:** 
  - `git push -u origin main`[cite: 82]
  - `git pull origin main`[cite: 84]
- **Pull Requests (PRs):** Proposing, reviewing, discussing, and merging feature branches safely into `main`[cite: 94].
- **Releases & Tags:** Marking version milestones using `git tag -a v1.0.0 -m "Release"` and pushing tags[cite: 100].
